网易云音乐适配

            
让网易云接入 Windows 系统媒体会话。

          

        

        
      


      

        

          Windows 的音乐卡片、音量面板和键盘媒体键都依赖系统媒体会话（SMTC）。网易云音乐桌面版默认不向系统上报播放状态，所以本应用读不到它的歌名与进度，也无法通过系统媒体键控制它。
        


        

          

            1
            

              安装 BetterNCM
              
网易云的本地插件加载器，从官方开源发布页安装。

            

          

          

            2
            

              安装 InfLink-rs
              
把网易云的歌曲、歌手、封面与播放进度桥接到 Windows SMTC。

            

          

          

            3
            

              重启网易云
              
播放任意歌曲，音乐组件会自动读取系统会话并刷新。

            

          

        


        

          
          

            纯本地开源桥接，不涉及账号数据，无封号风险
            

              BetterNCM 与 InfLink-rs 都在本机运行，只把播放信息交给 Windows 系统媒体会话，不会读取账号密码、不调用网易云私有接口、不上传听歌数据。两个插件均为独立第三方开源项目，请只从下方官方仓库下载。
